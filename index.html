Certificate installation

Trust the SigMohar

⚠️ Warning: This CA is provided for development and testing purposes only. It is not recommended for use in production environments.

Add the root certificate to your system's trust store so certificates issued by Sigmohar are recognized automatically, with no browser warnings. Pick your OS below — it's three commands.

bash — SigMohar-Roots
  1. 01

    Download SigMohar Roots

    $ curl -sSL https://sigmohar.com/static/install_roots_on_linux.sh | bash
zsh — SigMohar-Roots
  1. 01

    Download SigMohar Roots

    $ curl -sSL https://sigmohar.com/static/install_roots_on_mac.sh | bash
PowerShell — SigMohar-Roots
  1. 01

    Open PowerShell as Administrator, then download SigMohar Roots

    PS> Invoke-WebRequest -Uri "https://ca.sigmohar.example/r/sigmohar-root.crt" -OutFile "sigmohar-root.crt"
  2. 02

    Import it into the Trusted Root store

    PS> Import-Certificate -FilePath ".\sigmohar-root.crt" -CertStoreLocation Cert:\LocalMachine\Root
  3. 03

    Verify it was installed

    PS> Get-ChildItem -Path Cert:\LocalMachine\Root | Where-Object { $_.Subject -like "*Sigmohar*" }

    Or via Certificate Manager: run certlm.msc and check Trusted Root Certification Authorities.
